              Module	                                            Main features

              Dashboard	                         Users, leads, clients, follow-ups aur conversion summary
              User Management           	User create/edit, role assign, activate/deactivate
              Role Management	                Role create/edit aur permission assignment
              Permission Management	        System permissions ki master list
              Lead Management           	Lead create, assign, status, source, priority, follow-up
              Client Management	                Converted clients, contact details, documents, history
              Follow-up Management	        Calls, meetings, WhatsApp, reminders, next follow-up
              Task Management	                Task assign, due date, priority, completion
              Notes & Activities	        Lead/client notes aur complete activity timeline
              Reports                    	Lead report, conversion report, employee performance
              Notifications	                Pending follow-ups, overdue tasks, assigned leads
              Settings	                        Company details, lead status, source, system configuration
              Audit Logs	                Kis user ne kya create, edit ya delete kiya

           3. Role-permission

               Full = Complete access
               Team = Apni team ka data
               Own = Sirf apna assigned data
               View = Sirf dekh sakta hai
               No = Access nahi

                Module	          Super Admin	      Admin	        Manager	            Sales Executive  	 User
